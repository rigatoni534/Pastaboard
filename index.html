Pastaboard:

Greatest Keyboard

About Pastaboard

Pastaboard is a modern, Android design-first app that will give you a keyboard with great UI but you also don't have to sacrifice any of your features from Gboard, as the envisioned goal of this project is that you can easily switch to Gboard and not lose a single feature, but gain the good interface. The interface uses MD3E which I took straight from PixelPlayer, another Android project but is a music player using MD3E. I suggest you try it, it truly is an amazing little project. Needs more updates though.

Features

Design-First

Pastaboard focuses on a modern, Android MD3E design, to make you like typing. It will also look like something from a Pixel phone, even though Pixels don't use it.

Feature-Rich

Even though Pastaboard is design-first, it doesn't compromise on features. You'll have access to all the functionality you expect from a modern keyboard app, including predictive text, gesture typing, and a wide range of customization options, with the featureset and navigation feeling almost exactly like Gboard, so you won't have to learn a new interface just to type with your new UI.

Made For Anything

Phone keyboards are seriously advanced, and some take a lot of resources. But Pastaboard is designed from the start to run on even devices with 3GB of RAM. It takes virtually no RAM and CPU, but still has advanced features like text prediction and autocorrect.
